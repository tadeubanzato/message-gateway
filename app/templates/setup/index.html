Set up Message Gateway

Two quick steps. You'll connect email, SMS, push, Telegram and WhatsApp right after, from inside the app.

1 · Storage 2 · Administrator 3 · Your API key

Where should the gateway keep its data?

Accounts, message history and your saved credentials (encrypted) go here.

In Atlas, allow your IP under Network Access and use a user with read/write access.

Create the administrator account

The administrator runs this gateway. They can:

  • connect and change email, SMS, push, Telegram and WhatsApp providers, and add new ones
  • choose which provider each channel uses by default
  • create and revoke API keys
  • decide whether other people can sign up

Anyone else who signs up later can send messages but can't change any of this. Use a strong password. It can't be reset by email.

You're in. Save your API key

This is the only time you'll see this token. Store it in a password manager now. You can create more keys later.

Connect your AI agent (optional)

Run this in your terminal to let Claude Code send and check messages through the gateway. It contains your key, so run it yourself, not in a chat. Then restart Claude Code or run /mcp.
