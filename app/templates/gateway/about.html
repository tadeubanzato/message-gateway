How it works

Your programs call one API. The gateway puts each message in a queue, a background worker delivers it through the provider you connected (for example Mailjet, Twilio or Pushover), retries if the provider has a temporary problem, and records the result in the message log.

  • Connect providers in Settings (owner only).
  • Create keys for your programs in API keys.
  • Messages that keep failing are set aside instead of being lost.
