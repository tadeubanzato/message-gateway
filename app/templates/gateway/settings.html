Single sign-on (Cloudflare Access)

Optional. Let people sign in to this web portal with Cloudflare Zero Trust instead of typing a password. Create a self-hosted Access application in Cloudflare for this gateway's address, covering the portal (/gateway) only, so /mcp and /api keep working with their keys. Then paste its team domain and Application Audience (AUD) tag here. Accounts are matched by email; nobody is created automatically.

Save and Test only work from the protected address (behind Cloudflare Access), because they check the sign-in Cloudflare just gave you.

Public address

Shown to developers and AI agents on the About page (the API examples and the MCP endpoint). By default it's just the address you're browsing this page from right now - that's already right for most setups (localhost, a server's bare IP, a domain pointed straight at the container). Set this only if that's wrong, typically behind a reverse proxy or tunnel (nginx, Cloudflare Tunnel, ngrok) that doesn't forward the original address, so the gateway only ever sees its own internal one.
