Send a message

Use your user key and an API token from API keys. Tokens are shown only once, so paste yours in place of YOUR_TOKEN. Add "provider": "name" to pick a specific connected provider; without it the channel's default is used.

curl -X POST {{ base_url }}/v1/messages \
  -H "X-User-Key: {{ user_key }}" \
  -H "X-API-Token: YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"channel":"push","app":"default","body":"Hello from my gateway"}'
